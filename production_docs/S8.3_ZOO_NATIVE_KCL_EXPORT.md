## 1. Executive Summary

Stage S8.3 replaces the legacy OBJ-conversion export path with a Zoo-native export of the exact approved KCL model executed on live Zoo Engine via WebSocket.

The exported STL and STEP files originate directly from B-Rep CAD geometry generated by Zoo Engine over WebSocket (`wss://api.zoo.dev/ws/modeling/commands`) using Zoo's native `export` command—not from any locally reconstructed mesh or REST file conversion endpoints.

### 2.1 Enforced Prohibitions
- **OBJ Endpoint Ban:** HTTP REST `POST /file/conversion/obj/...` is completely removed from production selection.
- **Local Mesh Ban:** Local OBJ/STL mesh generators (`generate_adapter_obj`) raise `RuntimeError("PRODUCTION EXPORT VIOLATION")` whenever the production prohibition guard (`set_prohibit_local_obj(True)`) is active.
- **Payload Serialization Ban:** Wavefront OBJ string serialization (`_serialize_zoo_model_payload`) is completely eliminated from the production path.
- **Strict Hash Equality:** `SHA256(stored KCL bytes) == SHA256(KCL bytes executed for export)` is strictly enforced prior to execution.

## 3. Protocol & WebSocket Payload Schema

### 3.1 Zoo Modeling Gateway Connection
- **Endpoint:** `wss://api.zoo.dev/ws/modeling/commands`
- **Header:** `Authorization: Bearer <token>`
- **Response Framing:** MessagePack binary frame (`msgpack.unpackb` with pure Python `unpack_msgpack` fallback).

### 3.2 Native Export Command Specs

#### STL Native Export Command:
```json
{
  "type": "export",
  "entity_ids": ["<solid3d_uuid>"],
  "format": {
    "type": "stl",
    "coords": {
      "forward": {"axis": "y", "direction": "negative"},
      "up": {"axis": "z", "direction": "positive"}
    },
    "selection": {"type": "default_scene"},
    "storage": "binary",
    "units": "mm"
  }
}
```

#### STEP Native Export Command:
```json
{
  "type": "export",
  "entity_ids": ["<solid3d_uuid>"],
  "format": {
    "type": "step",
    "coords": {
      "forward": {"axis": "y", "direction": "negative"},
      "up": {"axis": "z", "direction": "positive"}
    },
    "selection": {"type": "default_scene"}
  }
}
```
