# Stage S10.4 — Exact Complex Profile Tracing and Honest Review

**Status:** Completed  
**Stage Lead:** Antigravity / Gemini  
**Date:** July 28, 2026  

---

## Executive Summary

Stage S10.4 implements exact tracing, millimeter scale calibration, and honest review for complex aluminium extrusion profiles. Instead of reducing intricate cross-sections (such as 40×40 mm T-slot extrusions with internal bores or multi-cavity profiles) to primitive shapes like squares or circles, InterfaceForge now extracts:

1. **Exact 2D Outer Boundary Contours**: Ordered vertices following the true non-convex extrusion perimeter (e.g. 20 exact points for a 40×40 mm T-slot profile).
2. **Enclosed Negative Regions**: Inner holes, cavities, and slots classified with explicit user decision controls (`include as opening`, `ignore`, `unsure`).
3. **Millimetre Scale Calibration**: Extracted from visible drawing text annotations or calibrated by explicit user input, with a mandatory scale confirmation gate before manufacturing profile approval.
4. **Feature-Mapped Dimensions**: Numerical dimensions linked to specific geometry feature IDs (`feature_ref`) and drawing text annotations (`source_annotation`), with unmapped values labeled `"Detected text, not yet mapped to geometry"`.
5. **Honest Review Experience**: Three view modes (`Source`, `Clean Trace`, `Overlay`), side-by-side SVG preview with transparent overlay over source drawings, clear guidance banners, and ADR-compliant primitive fallback labeling (`"Simplified envelope — not the exact cross-section"`).

## Architectural Compliance & ADR Alignment

- **ADR-001 (Canonical Schema Source of Truth):** `ScaleCalibration` and `TracedContour` decision models are persisted as canonical schema fields.
- **ADR-003 (Untrusted AI Outputs):** Initial scale calibration starts as `confirmed = False`. Profile approval is strictly gated until user confirms scale.
- **ADR-004 (Mandatory Approval Gate):** Interface approval enforces scale confirmation and geometric self-intersection checks.
- **ADR-012 (Scope Scoping & Primitive Fallback Labeling):** Primitive fallback is only activated upon explicit user choice and carries the mandatory badge: `"Simplified envelope — not the exact cross-section"`.
