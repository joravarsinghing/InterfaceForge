## 5. Official Contract Verification & Corrections

- **Official Zoo File Format API Contract:** The Zoo REST endpoint `POST /file/conversion/{src_format}/{dst_format}` converts uploaded CAD file byte streams (supported source formats: `obj`, `stl`, `step`, `gltf`, `ply`, `sldprt`, `catia`, etc.). It does not accept `zoo_model_id` in its request parameters.
- **Clarification of `zoo_model_id`:** `zoo_model_id` is an internal lineage tracking key saved on `ModelRevision` during 3D execution. It guarantees that an export request cannot succeed unless a valid Zoo Engine execution has previously occurred (`IF-EXPORT-003`).
