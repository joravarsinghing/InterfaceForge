**Project:** InterfaceForge (Zoo API Makeathon 2026)  
**Target:** Interface B profile only  
**Input Image:** [`samples/manual_qa/interface_b_original.jpg`](../samples/manual_qa/interface_b_original.jpg)  
**Status:** FAIL — **Corrected by S10.5G.1** (Previous PASS was generated from hardcoded annotation boxes, not a live Gemini coordinate pipeline; crop was oversized/misplaced and annotation coordinates were incorrectly treated as 0–1 normalized after crop+resize)

---

## 1. Executive Summary & Objective

In Stage S10.5F, high-fidelity tracing was established for Interface B. However, raw drawing annotations—specifically dimension lines, extension lines, leaders, arrowheads, center marks, and callout text—created false cuts and dragged outer profile boundaries.

Stage S10.5G resolves this by introducing a strict, deterministic annotation masking pipeline:
```
Interface B original drawing
→ Gemini identifies annotation regions only
→ deterministic masking removes those pixels from the original image
→ OpenCV high-fidelity tracing
→ corrected SVG and real overlay
```

**Key Constraint:** Gemini identifies annotation regions only. Gemini **must not** regenerate, redraw, simplify, or invent profile geometry.

## 3. Deterministic Cleanup & Edge Reconstruction

1. **Pixel Masking:** Masked annotation pixels are set to white background (`[255, 255, 255]`) in original pixel space.
2. **Preservation of Profile Boundary:** Mask boundaries stop strictly outside physical profile walls (`x=138` left wall, `x=627` right wall, `y=188` top wall, `y=627` bottom wall).
3. **Intersection Repair:** Small line gaps (1-2 pixels) at extension line junction points are deterministically repaired using local $3 \times 3$ morphological closing (`cv2.MORPH_CLOSE`), restoring collinear profile edge continuity without global smoothing or redrawing.
4. **Hole Geometry Restoration:** Removing interior center marks yields 4 clean 360° circular contours fitted as smooth Ø4.4 mm circles (`circularity > 0.70`).
