## 1. Executive Summary

Stage S7.1 optimizes the AI vision pipeline by configuring Google's `gemini-3.5-flash-lite` as the primary default model for interface profile extraction, while retaining `gemini-3.6-flash` as an automated single-request fallback for failed or low-confidence analysis.

This optimization reduces latency and API token consumption for ordinary inputs without altering the canonical design schema, approval workflow, or frontend review interface (per ADR-001, ADR-003, and ADR-004). All secret credentials remain strictly protected backend-side, and error log sanitization (`sanitize_error_message`) ensures no API keys or token strings are leaked.

### 2.2 Provider Abstraction & Metadata Recording
`GeminiAnalysisProvider` records standard metadata on accepted `AnalysisResult` objects:
- `model_used`: Identifies which model generated the accepted profile (`gemini-2.5-flash-lite` or `gemini-2.5-flash`).
- `latency_seconds`: Safe request processing duration in seconds.
- `fallback_triggered`: Boolean indicating whether fallback was executed.
- `usage_metadata`: Safe provider token metrics (`prompt_token_count`, `candidates_token_count`, `total_token_count`) extracted from SDK metadata without exposing payload content.

## 3. Fallback Execution Logic & Gating Rules

Fallback occurs **at most once** per analysis request.

### 3.1 Permitted Fallback Conditions
Fallback to `gemini-2.5-flash` is triggered ONLY when `GEMINI_VISION_FALLBACK_ENABLED=true` AND:
1. **Malformed Response:** Primary response fails JSON parsing or schema validation (`MalformedProviderResponseError`).
2. **Low Confidence Without Explanation:** Primary response returns confidence score `< 0.60` with an empty `rejection_reasons` list.
3. **Retryable Provider Error:** Primary request fails due to network timeout or transient 5xx provider error.

### 3.2 Prohibited Fallback Conditions (Gated Off)
Fallback to `gemini-2.5-flash` is explicitly PROHIBITED when:
1. **Valid Poor-Image Rejection:** Primary response provides explicit explanation strings in `rejection_reasons` (e.g. severe lighting glare or off-axis perspective distortion). The provider raises `AnalysisRejectedError` (`IF-ANALYSIS-400`) directly to request user re-capture.
2. **Non-Retryable Auth Error:** Primary request fails with 401 Unauthorized or `API_KEY_INVALID`.
3. **Fallback Disabled:** `GEMINI_VISION_FALLBACK_ENABLED=false` is set in configuration.
4. **Already Attempted:** A fallback request was already executed for the current analysis session (maximum 1 fallback request limit).
