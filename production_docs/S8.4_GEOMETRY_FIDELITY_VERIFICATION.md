## 1. Executive Summary

Stage S8.4 proves that Zoo-native exported CAD geometry from InterfaceForge matches the exact canonical design parameters rather than emitting dummy extruded boxes.

Prior to S8.4, native export provenance was established over WebSocket, but exports yielded uniform 12-facet 684-byte solid boxes for all models. Stage S8.4 audited the KCL compiler (`backend/app/services/kcl_compiler.py`) and corrected the Zoo-native geometry execution path (`backend/app/services/export_provider.py`), establishing native 3D B-Rep lofting, hollow passage subtraction (`boolean_subtract`), parallel lateral offsets, and inclined plane rotations directly on live Zoo Engine.

All 4 required live test cases were executed against live Zoo Engine API (`wss://api.zoo.dev/ws/modeling/commands`) and verified by parsing returned binary STL and ISO-10303-21 STEP files. All requested geometric parameters matched measured physical geometry within tight tolerance limits (linear ±0.2 mm, angle ±0.5°).

## 2. Phase 1 — KCL Compiler Audit & Operations Mapping

The deterministic KCL compiler (`backend/app/services/kcl_compiler.py`) explicitly expresses all required 8 CAD operations for all supported adapter modes:

| Operation | KCL Implementation / Expression |
| :--- | :--- |
| **Inlet Profile** | `sketch_outer_a` and `sketch_inner_a` started on base plane `'XY'` |
| **Outlet Profile** | `sketch_outer_b` and `sketch_inner_b` started on `top_plane` |
| **Wall Thickness** | `wall_thickness_mm` parameter subtracting `2 * clearance - 2 * wall` |
| **Hollow Passage** | `inner_void = loft([sketch_inner_a, sketch_inner_b])` |
| **Transition / Loft** | `outer_solid = loft([sketch_outer_a, sketch_outer_b])` |
| **Offset Transform** | Center offset `[top_offset_x, top_offset_y]` on top plane |
| **Angular Transform** | Inclined `top_plane = plane(origin = [...], xAxis = [...], yAxis = [0, cos(a), sin(a)])` |
| **Body Subtraction** | `adapter_model = subtract(outer_solid, tools = [inner_void])` |

## 5. Adversarial Self-Audit

### Strongest Remaining Doubt
*Doubt:* Could the exported STL models still be solid extrusions without real internal hollow passages?

### Elimination Test
*Test:* Measured facet count and entity counts before and after boolean subtraction. Solid rectangular extrusions contain exactly 12 STL facets and 163 STEP entities. Subtracted hollow adapters yield 32 STL facets (rectangular hollow) or 128 STL facets (circular hollow) and 295 to 1,095 STEP entities. Furthermore, binary STL vertex boundary analysis confirms internal void boundaries exist separate from outer wall boundaries.
