## 1. Executive Summary

Stage S8.2 corrects the production export pipeline so that generated STL, STEP, and KCL files are derived directly from the exact successful Zoo Engine model instance (`zoo_model_id` and SHA-256 `kcl_hash`), strictly satisfying ADR-001, ADR-002, ADR-005, ADR-006, and PRD requirements.

The local `generate_adapter_obj()` path is strictly prohibited from running during production exports (`ZooExportProvider`). A runtime guard (`set_prohibit_local_obj`) throws a `RuntimeError` if local OBJ generation is attempted in production mode.

---

## 2. Mandatory Architecture Compliance

The verified production pipeline is:

```text
canonical schema
  -> deterministic KCL (ADR-001/002)
  -> Zoo Engine execution (WebSocket modeling session)
  -> exact successful Zoo model reference (zoo_model_id + kcl_hash)
  -> Zoo API conversion (/file/conversion/obj/{stl|step})
  -> STL / STEP artifacts
```

### Governance Alignment
- **ADR-001 / ADR-002:** Canonical design schema remains sole source of truth; KCL is a generated artifact.
- **ADR-005:** Preserves last-known-good model revision across failed operations.
- **ADR-006:** Live Zoo Engine and Zoo File Format APIs handle 3D execution and format conversions.
- **ADR-013:** Error IDs (`IF-EXPORT-003`, `IF-EXPORT-005`) provide clear diagnostics and recovery steps.

## 3. Key Implementation Details

1. **Schema & Model Lineage (`app/models/schema.py` & `app/models/generation.py`):**
   - Added `zoo_model_id: Optional[str] = None` and `kcl_hash: Optional[str] = None` to `ModelRevision`, `ModelSucceedRequest`, `FormatExportDetail`, `GenerationJob`, and `ExportResult`.
2. **Prohibition Guard & Spy Instrumentation (`app/services/geometry_generator.py`):**
   - Added global prohibition flag `_PROHIBIT_LOCAL_OBJ_GENERATION` and call spy counter (`_LOCAL_OBJ_CALL_COUNT`).
   - `generate_adapter_obj()` raises `RuntimeError` ("PRODUCTION EXPORT VIOLATION...") when called during production export mode.
3. **Zoo Export Provider (`app/services/export_provider.py`):**
   - Rejects export requests missing `zoo_model_id` with `IF-EXPORT-003`.
   - Validates `kcl_hash` consistency with `IF-EXPORT-005`.
   - Constructs cache keys with model identity: `export_{project_id}_rev{model_rev}_zoo_{zoo_model_id[:8]}_{kcl_hash[:8]}.{fmt}`.
   - Derives 3D conversion payload directly without calling `generate_adapter_obj()`.
4. **Project Service Integration (`app/services/project_service.py`):**
   - Passes `zoo_model_id` and `kcl_hash` through `succeed_model_generation()`, `generate_exports()`, and `get_export_status()`.
